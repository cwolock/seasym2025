# Seventh Seattle Symposium in Biostatistics

## Introduction to causal inference using machine learning methods

This repository contains the course materials for "Introduction to causal inference using machine learning methods" at the Seventh Seattle Symposium in Biostatistics. 

The directories labeled `chapter_*` contain lecture PDFs. The `lab1` and `lab2` directories contain `R` Markdown files with code that we will run as exercises during lecture. 

To be prepared to run the lab code, you should install `R` and `R` Studio. Instructions for installing required packages are found on page 3 of the `lab1.pdf` file.
